Startup & shortcuts
Startup
Print Screen key
Windows is using Print Screen for the Snipping Tool
Turn off "Use the Print screen key to open screen capture" in Windows settings. Capta notices the change automatically.
Print Screen opens Capta
Works even when the toolbar is hidden.
Open capture (last used mode) PrtSc
Full screen, straight to clipboard Shift + PrtSc
Active window Alt + PrtSc
Record video Ctrl + PrtSc
Grab text from screen Ctrl + Shift + PrtSc
Win + Shift + S is reserved by Windows and will still open the Snipping Tool.
